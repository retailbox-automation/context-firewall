# Eval: rules-only mode (`--local`)

Version 0.1.0, seed 20261109, 300 synthetic documents (payment-page text, email, OCR-style text with noise).
Every document carries all 17 categories plus decoys (order and tracking numbers, phones, dates, UUIDs, git SHAs, amounts, Luhn-valid numbers with an unknown IIN, postal codes, EIN-shaped invoice numbers).
The corpus is regenerated by `npm run eval` and is not committed.

A truth span counts as found when a finding of the same category overlaps it. A finding is a false positive when no truth span of its category overlaps it.

Limits: the corpus is synthetic and written by the same people as the detectors, so these numbers are an upper bound on real pages. OCR noise here is limited to doubled separators, glued labels and character swaps outside the secret itself; digits changed inside a secret are not covered. OTP and EIN-shaped numbers are `likely` matches by design and cost precision.
